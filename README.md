# Search-Inventory:

## How to download/use-
### Download & Install
1. download from Github
2. download InelliJ
3. open `search-inventory` file in IntelliJ
4. In `search-inventory` open `src/main/java/com.pluralsight` and under `/com.pluralsight` select `Main`
5. in `Main` above the coding window where you see `Current File` on the right of it click the start button(`▶` when you hover over it should say `Run 'Main.java'`)
   that should start the program
